# Security policy

## Een kwetsbaarheid melden

Vond je een kwetsbaarheid in deze repository? Meld die **niet** via een openbare issue of pull request.

Gebruik in plaats daarvan **Security → Report a vulnerability** in deze repository. Je melding is dan alleen zichtbaar voor de beheerder.

- Je ontvangt binnen **5 werkdagen** een eerste reactie.
- We houden je op de hoogte van de afhandeling en vermelden je (als je dat wilt) bij de oplossing.

## Ondersteunde versies

Alleen de laatste versie op de `main`-branch wordt ondersteund.
